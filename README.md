# OmniPost-AI

A Spring Boot application that lets you **upload a video once** and automatically:

1. **Generates AI-powered content** (title, caption, hashtags) via OpenAI
2. **Creates a thumbnail** (FFmpeg-extracted frame or branded placeholder)
3. **Publishes the video** to all configured platforms (YouTube, Instagram) in one shot

No need to write copy or upload separately anywhere — just upload once and everything is handled.

---

## Architecture

```
Upload Video (REST API)
        │
        ▼
VideoService (orchestration)
   ├── AIContentService    ─── OpenAI API (title, caption, hashtags)
   ├── ThumbnailService    ─── FFmpeg / Java2D placeholder
   └── PlatformPublisherService
           ├── YouTubeService   ─── YouTube Data API v3
           └── InstagramService ─── Instagram Graph API (Reels)
```

## Quick Start

### Prerequisites
- Java 17+
- Maven 3.8+
- (Optional) FFmpeg on PATH for frame-extracted thumbnails

### Run locally

```bash
# Clone and build
mvn clean package -q

# Start the application
java -jar target/omnipost-ai-1.0.0-SNAPSHOT.jar
```

The server starts on **http://localhost:8080**.

### Upload a video

```bash
curl -X POST http://localhost:8080/api/videos/upload \
     -F "file=@/path/to/your/video.mp4"
```

**Response (201 Created):**
```json
{
  "videoId": 1,
  "originalFileName": "my_video.mp4",
  "status": "PUBLISHED",
  "title": "AI-Generated Title",
  "caption": "An engaging caption generated by AI ✨",
  "hashtags": ["trending", "viral", "content"],
  "thumbnailPath": "/absolute/path/to/thumbnail.jpg",
  "publishResults": [
    { "platform": "YOUTUBE",   "status": "SUCCESS", "platformPostUrl": "https://www.youtube.com/watch?v=..." },
    { "platform": "INSTAGRAM", "status": "SUCCESS", "platformPostUrl": "https://www.instagram.com/p/..." }
  ]
}
```

### Other endpoints

| Method | Path                    | Description                          |
|--------|-------------------------|--------------------------------------|
| POST   | `/api/videos/upload`    | Upload and publish a video           |
| GET    | `/api/videos`           | List all uploaded videos             |
| GET    | `/api/videos/{id}`      | Get details of a specific video      |
| GET    | `/api/videos/{id}/stream` | Stream/download the video file     |

## Configuration

All settings are in `src/main/resources/application.properties` and can be overridden via environment variables:

| Property | Env Variable | Description |
|---|---|---|
| `omnipost.openai.api-key` | `OPENAI_API_KEY` | OpenAI API key for AI content generation |
| `omnipost.youtube.client-id` | `YOUTUBE_CLIENT_ID` | YouTube OAuth2 client ID |
| `omnipost.youtube.client-secret` | `YOUTUBE_CLIENT_SECRET` | YouTube OAuth2 client secret |
| `omnipost.youtube.refresh-token` | `YOUTUBE_REFRESH_TOKEN` | YouTube OAuth2 refresh token |
| `omnipost.instagram.access-token` | `INSTAGRAM_ACCESS_TOKEN` | Instagram Graph API access token |
| `omnipost.instagram.account-id` | `INSTAGRAM_ACCOUNT_ID` | Instagram Business/Creator account ID |
| `omnipost.server.base-url` | `SERVER_BASE_URL` | Public URL of this server (used for Instagram video URL) |

If credentials for a platform are not set, publishing to that platform is **skipped gracefully** (status `SKIPPED`), and other platforms still proceed.

### YouTube Setup
1. Create a project in [Google Cloud Console](https://console.cloud.google.com/)
2. Enable the **YouTube Data API v3**
3. Create OAuth 2.0 credentials (Desktop app)
4. Obtain a refresh token using the OAuth 2.0 playground or a helper script
5. Set the three `YOUTUBE_*` environment variables

### Instagram Setup
1. Create a [Meta Developer App](https://developers.facebook.com/)
2. Add the **Instagram Graph API** product
3. Connect an Instagram Business or Creator account
4. Generate a long-lived access token
5. Set `INSTAGRAM_ACCESS_TOKEN` and `INSTAGRAM_ACCOUNT_ID`

> **Note:** The Instagram Graph API requires a **publicly accessible video URL**. Set `SERVER_BASE_URL` to your public server address so Instagram can fetch the video.

## Development

```bash
# Run tests
mvn test

# Build without tests
mvn package -DskipTests

# H2 database console (development only)
# http://localhost:8080/h2-console
# JDBC URL: jdbc:h2:file:./omnipost-db
```

Uploaded videos are stored under `uploads/videos/` and thumbnails under `uploads/thumbnails/` (relative to the working directory). These are excluded from version control via `.gitignore`.
